# 2: Controls

The game's controls are:

___
	W A S D or arrow keys: move
	F or left click: fire
	right click: nothing
	P: toggle paused
	Q: cycle gun left
	E: cycle gun right
	R: restart game (only while paused or choosing)
	M: main menu
